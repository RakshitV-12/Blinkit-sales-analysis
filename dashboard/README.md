# Blinkit Sales Dashboard

This directory houses resources, assets, and documentation for the interactive BI dashboard (Power BI / Tableau).

## Dashboard Overview
The interactive dashboard complements the Python Exploratory Data Analysis (EDA) by providing executive-level KPIs, visual segment drill-downs, and dynamic filtering across outlet establishment years, outlet types, and product categories.

## Suggested Dashboard Assets
Place your dashboard export files and visual screenshots here:

## Key Visualizations Included
1. **Executive KPI Cards**: Total Sales ($18.59M), Average Sales per Item ($2,181), Average Item MRP ($140.99), and Number of Unique Items (1,559).
2. **Sales by Outlet Type**: Horizontal bar chart comparing Supermarket Type 1, 2, 3, and Grocery Store volume and average revenue.
3. **Category Contributions**: Treemap/Bar chart highlighting Fruits & Vegetables and Snack Foods as top revenue drivers.
4. **Fat Content Share**: Donut chart detailing Low Fat (64.73%) vs. Regular (35.27%).
5. **Outlet Establishment Timeline**: Trend line comparing store establishment years against outlet performance.
6. **Location Tier Breakdown**: Tier 1, Tier 2, and Tier 3 sales distributions.
